# Cyber Security & SOC Toolkit

A comprehensive collection of security assessment tools, web scanners, authentication utilities, and security project assignments.

## Repository Contents

| Project / Module | Description |
|---|---|
| **Application Security** | Web security application implementation and defense mechanisms |
| **Authentication Toolkit** | Toolkit for user authentication flows, verification, and security testing |
| **Secure Multi Domain Payment Company** | Enterprise-grade multi-domain secure payment processing simulation |
| **Security IP Range Scanner** | IP network scanner to analyze active hosts across IP ranges |
| **Security Port Scanner** | Network port scanner for service discovery and port auditing |
| **Sub Domain Enumeration** | Tool for discovering subdomains using wordlist-based enumeration |
| **Web Vulnerability Scanner** | Automated vulnerability scanner for web applications (includes web UI & reports) |
| **Cyber Warfare & Stuxnet Assignment** | Case study and analytical report on Stuxnet cyber warfare |

---

## Setup & Requirements

# Example setup for modules with requirements.txt
